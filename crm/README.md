# Мини-CRM NikiRent

Одна страница: квартиры, коммуналка и выплаты за апрель и май. Сервера, базы и входа нет. Оформление то же, что у дашборда обращений.

## Как открыть

Нужны Node.js и npm.

```bash
npm install
npm run dev
```

Адрес: http://localhost:3000

Страница сразу читает `public/data/kommunalka.xlsx`. Кнопка «Загрузить файл» принимает другой xlsx или csv и пересчитывает экран только в этой вкладке.

Проверка контрольных сумм:

```bash
npm run check-data
```

Файл данных собирается из расчёта в родительской папке:

```bash
python ..\export_crm.py
```
